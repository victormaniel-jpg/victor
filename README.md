# Lista de Exercícios 02 - Programação Orientada a Objetos

Exercícios de Java cobrindo:
- **Parte 1**: classes, encapsulamento e níveis de acesso (ex01-ex05)
- **Parte 2**: construtores e sobrecarga (ex06-ex10)
- **Parte 3**: toString, igualdade e referência (ex11-ex15)

## Estrutura

Cada pasta `exNN/` contém a(s) classe(s) do exercício e um `Main.java` com a demonstração.

## Como compilar e executar

```bash
cd exNN
javac *.java
java Main
```

Para o exercício 5 (pacotes `sensor` e `teste`):
```bash
cd ex05
javac sensor/Sensor.java teste/TesteSensor.java -d bin
cd bin
java teste.TesteSensor
```
